# Deribit historical option instrument metadata (N13)

Read-only audit, 2026-09-28. No trades, prices, signals, or performance were requested or read. Two public GETs were made to `history.deribit.com`; total received body bytes: 707, under the 32,000,000-byte cap. Receipts, exact URLs, HTTP status, headers, SHA-256, and raw bytes are in `options-instrument-probe-manifest.json` and `research/cache/goal-seven/options-instrument-probes/`.

`public/get_instrument?instrument_name=BTC-19NOV21-56000-P` returned HTTP 200 (706 bytes; SHA-256 `081d08ac0f3fb9d9dab6e5e2e52af47339330ceab1762c9470abaaeec3caaf77`). This real expired instrument was already named in the local 2021 probe metadata. The response confirms: `instrument_name=BTC-19NOV21-56000-P`, `kind=option`, `strike=56000`, `option_type=put`, `expiration_timestamp=1637308800000`, `creation_timestamp=1635408007000`, `contract_size=1`, `base_currency=BTC`, `settlement_currency=BTC`, `quote_currency=BTC`. Timestamps are epoch milliseconds. The response's `state` value was null. This establishes that exact-name lookup can enrich a known archived instrument with the needed contract metadata; it does not provide a historical list of all instruments.

A metadata-only request to `public/get_instruments?currency=BTC&kind=option&expired=true` returned HTTP 200, but advertised `Content-Length: 76485600` (76,485,600 bytes), exceeding the 32,000,000-byte cap. The client stopped after one byte; the partial body is preserved and hashed (`021fb596db81e6d02bf3d2586ee3981fe519f275c0ac9ca76bbcf2ebb4097d96`). No inventory was downloaded or parsed. Official docs say `expired=true` returns instruments still in the live table with state `delivered` (recently expired), while older expired/archived instruments no longer listed there require exact-name `get_instrument`; thus this endpoint is neither a practical capped catalog nor complete historical discovery.

Sources: [Deribit public/get_instrument](https://docs.deribit.com/api-reference/market-data/public-get_instrument) documents lookup of expired/archived instruments by exact name and the contract fields; [Deribit public/get_instruments](https://docs.deribit.com/api-reference/market-data/public-get_instruments) documents the limited meaning of `expired=true`. Metadata lookup appears feasible without aggregating trades once an instrument name is known. Finding every historical option instrument remains unresolved; use already observed trade instrument names only if that separate acquisition is authorized, then enrich them one-by-one. No pricing or cost conclusion follows from this metadata audit.
