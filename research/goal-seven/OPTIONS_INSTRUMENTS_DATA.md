# Deribit option-instrument catalog acquisition (N13)

Read-only metadata acquisition via the official `history.deribit.com/api/v2/public/get_instruments` endpoint, on 2026-09-28. Two GETs only: `currency=BTC` and `currency=ETH`, each with `kind=option&expired=true&include_old=true`. HTTP 200 for both. No API key, trades, prices, signals, PnL, or `is_active` filtering. The exact URLs, request/receipt UTC, status, response headers, byte counts, checksums, and per-field quality counts are recorded in `options-instruments-data-manifest.json`.

BTC response: 76,485,600 bytes, 122,747 records. ETH: 77,275,328 bytes, 124,692 records. Total raw response 153,760,928 bytes, below 160,000,000 per response and 320,000,000 total. The original response entities are preserved as deterministic gzip files; manifest stores SHA-256 for both decompressed response bytes and gzip artifacts. Normalized JSON arrays retain every record and the requested metadata fields, with `strike` and `contract_size` as decimal strings. Both instruments and timestamps were present in all records; no duplicate instrument names or invalid timestamps/numeric fields were observed. No records were dropped. Local verification: `python scripts/download-goal-option-instruments.py --verify` passed.

Observed creation timestamp ranges: BTC 2016-07-13 through 2026-09-28; ETH 2019-03-21 through 2026-09-28. This is the inventory returned by this request at acquisition time, not proof of point-in-time availability at any historical date. `expired=true&include_old=true` returns a metadata catalog useful for enriching known instruments without a large set of exact-name requests, but presence in this current catalog must not be treated as PIT membership or evidence that the instrument was listed at a particular historical decision time. Raw server records and metadata remain available for independent audit; do not infer survivor-free historical universes from the current response.

Run `python scripts/download-goal-option-instruments.py --verify` for offline hashes. Acquisition is bounded at 3 GETs, 160,000,000 bytes per response, 320,000,000 bytes total, and a 60-second request timeout; it refuses to overwrite existing outputs. Cache files are in ignored `research/cache/goal-seven/options-instruments/`.
