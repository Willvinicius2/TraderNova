# Validação das candidatas

Trabalho separado do laboratório (`research/lab`): pega as CANDIDATAS do BTC e testa recalibração, comprado/vendido, filtro de regime, walk-forward, outros ativos e referências ingênuas. Usa o motor, as estratégias e os dados do laboratório sem alterá-los.

- `RELATORIO.md`: conclusões.
- `RESUMO.md`: tabelas geradas por `resumo.py`.
- `validar.py`, `carteira.py`, `dados_fx.py`, `config.json`, `benchmarks/`: código e configuração.
- `results/`: um JSON por estratégia e `_carteira.json`.
